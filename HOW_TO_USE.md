# 🎬 Digital Slate - Quick Start

## Open the App

https://jonathandevoypcd.github.io/DigitalCinema/

## On Set Workflow

### Edit a Shot
1. Choose scene from sidebar
2. Click scene to pick a shot
3. Edit:
   - Take number (use +/- buttons)
   - Setup (suggested or custom)
   - Description, location, scene name

### Present to Camera
1. Click **Present slate** button
2. Full-screen view ready for camera
3. Click navigation buttons:
   - Previous/Next shot
   - Previous/Next scene
   - Change setup (edit camera angle)

### Back to Edit
1. Click **Back to editor**
2. Changes saved automatically

## Sync to Cloud

**Before wrapping:**
- Click **🔄 Sync** button (top right)
- Shows status: ✅ Synced!
- All edits uploaded to cloud

**On your PC:**
- Edits stay in browser storage
- Can view same app anytime

## What Auto-Saves

✅ Take numbers  
✅ Setup selections  
✅ Scene names  
✅ Shot descriptions  
✅ Location notes  
✅ Project name  

## Tips

- **Local saves** happen automatically as you type
- **Cloud syncs** when you click 🔄 Sync
- **Offline** still works (syncs when online)
- **Multiple takes** - use +/- button to increment takes
- **Quick setup** - tap suggested coverage buttons
